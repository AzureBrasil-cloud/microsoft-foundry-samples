# Publishing AI Agents to Microsoft Teams and Microsoft 365 Copilot 🤖

This guide documents how to create, configure, and publish AI agents built in Microsoft Foundry to Microsoft Teams and Microsoft 365 Copilot.

This repository is designed to provide a clear path to publish agents from Microsoft Foundry to Microsoft Teams and Microsoft 365 Copilot with minimal friction.

It includes publishing workflows, governance notes, and real-world examples of how to operationalize AI agents inside Microsoft 365.

## What’s inside 📂

- **overview.md** 📘: Detailed description of the publishing process and setup
- **examples.md** 🧩: Practical use cases and real-world publishing scenarios
- **troubleshooting.md** 🛠️: Common problems and fixes during the publish flow
